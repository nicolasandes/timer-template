# Audio Assets

This directory should contain audio files for timer alerts.

## Required Files

- `beep.mp3` - Countdown beep (plays during last 3 seconds)
- `start.mp3` - Start interval sound (plays when work/rest phase begins)
- `end.mp3` - Workout complete sound (plays when all rounds are finished)

## Recommendations

- **Duration:** Keep sounds short (0.5-2 seconds)
- **Format:** MP3 is recommended for cross-platform compatibility
- **Volume:** Ensure sounds are normalized to similar volumes

## Free Sound Resources
